The Foundation — What I Actually Do

Before talking about results, let me be specific about what "web designer and developer" actually means in my context — because it is a phrase that gets used loosely.

Web Design

I design websites from scratch. Every visual element — layout, typography, colour system, spacing, button design, card structure, animation, mobile breakpoints — is designed intentionally. I do not use pre-built Wix templates or WordPress themes. Every site I build has a unique visual identity matched to the brand it represents.

My design language uses sky-blue and white premium palettes, clean sans-serif typography with Poppins and Inter, smooth hover animations, mobile-first grid layouts, and visual hierarchy that moves the user naturally toward enquiry or purchase. You can see this in every project at rebrar.in.

Web Development

I build websites in HTML, CSS, and vanilla JavaScript — no WordPress, no page builders, no frameworks that add bloat. This approach produces websites that load in under 2 seconds, score 90+ on Google PageSpeed, and never break because a plugin updated.

For clients who need dynamic features — admin panels, Firebase databases, real-time content management, blog systems, user authentication — I integrate Firebase (Firestore, Auth, Storage) with custom JavaScript. The result is a fully functional web application that feels like a SaaS product but runs on static hosting without server costs.

SEO

Every website I build is SEO-optimised from line 1 of the code. This is not an afterthought. It is built into the structure:

  • Semantic HTML5 with correct heading hierarchy
  • Full Schema.org structured data — LocalBusiness, Person, BlogPosting, FAQPage, BreadcrumbList
  • Unique, keyword-researched meta titles and descriptions per page
  • Open Graph and Twitter Card tags for social sharing
  • Geo tags for location-based ranking (critical for Kashmir travel businesses)
  • XML sitemap submitted to Google Search Console
  • robots.txt configured correctly
  • Canonical tags on every page to prevent duplicate content
  • Core Web Vitals optimised — LCP, FID, CLS

Meta Ads

Beyond websites, I run Meta (Facebook & Instagram) advertising campaigns for clients — audience targeting, creative strategy, A/B testing, conversion optimisation. I am a Meta ads specialist with experience managing campaigns across travel, hospitality, e-commerce and local business categories. More on this in a separate post.

What Makes My Work Different from Other Web Designers in India

India has hundreds of thousands of people who call themselves web designers. Most of them produce the same output: a slow WordPress site built on a ₹499 premium theme, with stock photos, generic copy, and zero SEO. It looks fine on the day it launches and achieves nothing after that.

Here is what I do differently:

1. SEO Is Not Optional — It Is the Point

Every website I build has one primary purpose: to rank on Google and generate leads for the client. Good design is a means to that end. A beautiful website that does not rank is a liability, not an asset. I refuse to deliver websites that do not have a path to ranking.

This approach has produced measurable results: multiple J&K travel clients ranking on Page 1 of Google for their target search terms within 3–6 months of launch.

2. Clean Code — No Bloat, No Dependency Chains

Building in pure HTML, CSS and JavaScript means the websites I deliver are fast, stable, and maintainable. No WordPress plugin conflicts. No theme update breaking the layout. No hosting requirement for PHP servers. Sites run on static hosting — Netlify, Vercel, GitHub Pages — often for free or near-free. The client's hosting cost goes from ₹5,000/year to zero.

3. Mobile-First Because India Is Mobile-First

India's internet is mobile. Over 75% of all web traffic in India comes from mobile devices. Over 80% of tourist searches for Kashmir travel happen on phones. Every site I build is designed on mobile first — then scaled up to desktop. Not the other way around.

4. I Build Products, Not Just Websites

I have built two product companies — rebrar.in and MakeMe Top. I understand what it means to build something that has to work reliably at scale, not just look good in a client demo. That product thinking carries into every website I build for clients. I ask: what does this website need to achieve in six months? — not just: what does it need to look like today?

5. I Am From Where the Problems Are

Being based in Srinagar means I understand Kashmir's travel industry from the inside. I know the difference between a budget houseboat and a luxury one. I know which keywords tourists actually search for. I know what a first-time Kashmir visitor is worried about and what a verified badge means to them. This contextual knowledge produces better websites than any outsourced agency could deliver from Delhi or Bangalore.
